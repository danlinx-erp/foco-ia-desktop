# Foco IA para Mac e Windows

Instaladores do app Foco IA. O código da plataforma não fica aqui; este repositório só publica as versões.

- **Mac** (Apple Silicon e Intel): [Foco-IA-Mac.dmg](https://github.com/danlinx-erp/foco-ia-desktop/releases/latest/download/Foco-IA-Mac.dmg)
- **Windows**: [Foco-IA-Windows.exe](https://github.com/danlinx-erp/foco-ia-desktop/releases/latest/download/Foco-IA-Windows.exe)

Depois de instalar, conecte o computador em **Configurações → Meu computador** na sua conta Foco IA.
